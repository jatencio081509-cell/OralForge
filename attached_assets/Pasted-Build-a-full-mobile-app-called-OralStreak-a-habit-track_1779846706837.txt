Build a full mobile app called “OralStreak”, a habit-tracking app focused on enforcing proper daily oral hygiene through verified actions, streaks, and accountability.

Use:

* Expo React Native (TypeScript)
* Supabase (optional backend, but structure for it)
* Offline-first local storage (AsyncStorage or SQLite)

The app must be structured, production-ready, and modular.

⸻

🧠 CORE APP RULE

The app is NOT a simple checklist.

Every action MUST be verified:

* Brushing cannot be logged manually
* Brushing must be completed through a timer
* Timer must fully complete (no early completion allowed)

⸻

🪥 DAILY REQUIREMENTS SYSTEM

A user’s day is only “Complete” if ALL are done:

Brushing (2x daily)

* Morning brushing
* Night brushing
* Must use built-in timer (2 or 3 minutes selectable)
* Timer completion = verification

Flossing

* 1x per day required

Mouthwash

* 1x per day required

⸻

📊 STREAK SYSTEM

Track:

* Brushing streak (morning + night consistency)
* Full Oral Care Streak (all 4 tasks completed in a day)
* Total Full Days Completed (lifetime counter)

Rules:

* Missing brushing breaks brushing streak
* Missing any task breaks full streak

⸻

🔁 RECOVERY SYSTEM

If user misses brushing:

* they enter “Comeback Mode”
* streak is still punished (no forgiveness)
* reminders become softer, not spammy

⸻

🧾 MISSED SESSION FLOW

If a user misses brushing:

* app MUST ask: “Why did you miss it?”
* user must select a reason (required input)

⸻
